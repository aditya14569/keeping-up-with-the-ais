- ClickHouse (clickhouse.com/blog), DuckDB (duckdb.org/news), Apache Iceberg, Delta Lake, Apache Spark, Apache Flink, Cassandra, ScyllaDB, CockroachDB, Elasticsearch/OpenSearch

## Rules
- Defaults and limits (page sizes, timeouts, config values) come from official docs, with the link.
- Vendor performance claims are claims. Say so.
- Never cite a page you haven't actually opened.
