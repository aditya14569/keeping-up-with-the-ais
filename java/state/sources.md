# Sources: Java – Beautifully Broken

## 1. Official (always check first)
- OpenJDK: openjdk.org/projects/jdk/ (release pages, JEP lists), openjdk.org/jeps/<n>, jdk.java.net (GA and early-access builds)
- Oracle: oracle.com/java news, docs.oracle.com/en/java/javase/<ver>/ (language changes, migration guide), Java SE support roadmap
- inside.java (Oracle's Java team blog), dev.java (tutorials)
- Spring: spring.io/blog, spring.io/projects, GitHub release notes for spring-boot / spring-framework
- Jakarta EE (jakarta.ee/blogs), Quarkus (quarkus.io/blog), Micronaut, Hibernate (in.relation.to), Gradle/Maven release notes, GraalVM release notes
- Distributions: Adoptium/Temurin, Azul, BellSoft (Liberica), Amazon Corretto, Microsoft Build of OpenJDK

## 2. Trusted outlets
- InfoQ Java news roundups (weekly) and articles: infoq.com/java/news
- foojay.io, JetBrains Java blog, Baeldung (tutorials; for "Go deeper" links)

## 3. Engineering blogs (real-world examples)
- Netflix Tech Blog, Uber Engineering, LinkedIn Engineering, Airbnb, Shopify, Atlassian, Datadog, AWS Java blog

## 4. Community signal (discovery only; cite the original)
- r/java, Hacker News, Java Champions on social media, JUG talks, Devoxx/JavaOne talks

## Rules
- JEP numbers, statuses and release versions come from openjdk.org or official release notes.
- Vendor benchmark numbers are claims. Say so.
- Never cite a page you haven't actually opened.
