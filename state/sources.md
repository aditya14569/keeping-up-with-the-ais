# Where to look (check every layer, every day)

## 1. Primary sources (announcements)
- OpenAI news + developer changelog: openai.com/news, developers.openai.com/api/docs/changelog
- Anthropic news: anthropic.com/news
- Google DeepMind / Gemini: blog.google/technology/ai, deepmind.google/discover/blog
- Meta AI: ai.meta.com/blog
- SpaceXAI / xAI, Mistral, DeepSeek, Qwen (Alibaba), Moonshot (Kimi), MiniMax, Microsoft AI, Apple ML, NVIDIA blog
- Search "<lab> announces" / "<lab> launches" for the last 24h

## 2. Tech press
- TechCrunch AI, The Verge AI, Ars Technica, Reuters technology, CNBC tech, The Next Web, SiliconANGLE, 9to5Mac/9to5Google for product launches
- India angle: Economic Times tech, Mint tech, MeitY / IndiaAI announcements

## 3. Research and tools
- Hugging Face trending models and papers (huggingface.co/papers)
- arXiv cs.CL / cs.AI highlights, GitHub trending (Python, TypeScript)
- OpenRouter new models, Vercel AI Gateway / Cloudflare AI changelogs

## 4. Community signal
- Hacker News front page (AI stories), developer blogs, ThursdAI, well-known AI newsletters (for discovery only; always cite the original source)

## Source quality rules
- Prefer the original announcement or a reputable outlet over aggregators.
- Company performance claims are written as claims ("the company says...").
- Rumours and leaks: only if widely reported, and labelled as such.
- Never cite a page you have not actually seen in results or fetched.
