# Part 1 · Learn one thing

## 🔓 Open-weight vs closed models (and running AI at home)

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 1 · HOW LLMS WORK</span>

**Every model is, in the end, a giant file of numbers called weights. The real question is whether you're allowed to download that file.**

**Closed models** (GPT, Claude, Gemini) stay on the company's servers. You send text over the internet and **pay per token**. **Open-weight models** (Qwen, DeepSeek, Mistral, Reflection's Beam) let you **download the weights** and run them on your own machine or server.

**Analogy:** a closed model is **a restaurant**. The food is great, but you eat there, at their prices, by their rules. An open-weight model is **a frozen meal you take home**: you can reheat it anywhere and add your own spices (fine-tuning). But you usually **don't get the recipe**, meaning the training data and code. That's why **"open-weight" is not the same as "open source."**

### Will it fit on my laptop?

**The weights must fit in memory.** A handy rule: memory ≈ **parameters × bits per weight ÷ 8**. Squeezing each weight from 16 bits down to about 4 is called **quantization**, and it's how big models fit on normal machines.

```viz:bars
title: "Rough memory just for the weights, at ~4 bits per weight"
bars:
  - {label: 3B model, value: 1.5, display: "~1.5 GB"}
  - {label: 27B (Underdog's model), value: 13.5, display: "~13.5 GB", highlight: true}
  - {label: 501B (Beam), value: 250, display: "~250 GB"}
  - {label: ~1T (Mistral Large 4), value: 500, display: "~500 GB"}
note: "Our own arithmetic using the rule above; real files and running overhead add more. LM Studio recommends 16 GB+ of RAM."
```

So **a 3B or 8B model runs on most laptops**, a 27B model needs a well-stocked Mac or a good GPU, and the trillion-parameter giants are **server-only**.

**Which should you pick?** A simple rule: **prototype on a closed API**, because it's the fastest way to find out if your idea works. Move to open weights when **privacy, offline use or a huge volume of calls** matters more than having the very best model. Many teams end up using both: a small local model for easy, private jobs, and a frontier API for the hard ones.

**Why now?** In two days, **two big open-weight models** (Beam and Mistral Large 4) were announced, and a startup launched **Underdog, an assistant that runs a 27B model entirely on your PC** (Quick hits).

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Weights:** the billions of numbers a model learns in training. They *are* the model.
- **Quantization:** storing each weight with fewer bits, so the model gets smaller and faster, with a small loss in quality.
- **GGUF:** a popular file format for local models; it packs the weights plus the info needed to run them. [(Hugging Face)](https://www.huggingface.co/docs/hub/en/gguf)
- **Licence:** the rules for using the weights. Some allow anything; others limit commercial use.
</div>

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** install **LM Studio**, search for a small model (3B–8B), download it and chat. **Then turn off your Wi-Fi.** It keeps working, because nothing leaves your machine. [(LM Studio)](https://lmstudio.ai/docs/app/system-requirements)
- **Some code:** with **Ollama** installed, one line pulls a model from Hugging Face and starts a chat: [(Hugging Face)](https://huggingface.co/docs/hub/en/ollama)

```bash
ollama run hf.co/bartowski/Llama-3.2-3B-Instruct-GGUF
```
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: swap the cloud for localhost**

Ollama speaks the **OpenAI API format**, so existing code mostly works by changing one line: [(Ollama)](https://docs.ollama.com/api/openai-compatibility.md)

```python
from openai import OpenAI
client = OpenAI(base_url="http://localhost:11434/v1/",
                api_key="ollama")  # required but ignored
r = client.chat.completions.create(
    model="hf.co/bartowski/Llama-3.2-3B-Instruct-GGUF",
    messages=[{"role": "user", "content": "Hi!"}])
print(r.choices[0].message.content)
```

- **Pick a quantization** with a tag, like `:Q8_0` or `:IQ3_M`. With no tag, Ollama uses **Q4_K_M**, a good default.
- **Mixture-of-experts models:** the *total* parameters decide the memory you need; the *active* ones decide the speed.

**Gotcha:** the local API isn't a perfect copy. Ollama's docs say **image URLs, `tool_choice` and logprobs aren't supported**; send images as base64.
</div>

## Top story 2 · OpenAI's model wrote 722 maths papers

<span class="tag watch">CLAIMS · BEING CHECKED</span><span class="tag learn">RESEARCH</span>

**What happened.** OpenAI released **722 mathematical manuscripts**, grouped into **372 families**, produced by an **internal model it hasn't released**. The work spans number theory, geometry, computer science and mathematical physics, and sits in a **public GitHub repo**. [(OpenAI)](https://openai.com/index/sharing-ai-progress-in-mathematics/) [(Interesting Engineering)](https://interestingengineering.com/ai-robotics/openai-largest-math-release-lean-proofs)

```viz:flow

      style: warn
  - - label: Manuscript
      sub: on GitHub
note: "Simplified from OpenAI's post and Interesting Engineering. OpenAI chose which results to include."
```

**The details that matter:**

- **Lean** is a programming language for proofs: **a computer checks every logical step**. Many manuscripts have Lean versions, but **not all**, and OpenAI warns the unformalized ones **could contain issues**. [(Unite.AI)](https://www.unite.ai/openai-releases-722-math-manuscripts-from-an-unreleased-ai-model/)
- **Each accepted result took about three hours** of ChatGPT Pro–level thinking, on average. The model was tried on **roughly 4,000 problems**.
- **What's missing:** the model's name, the prompts, and **outside replication**. OpenAI alone decided what was significant enough to include. [(Runtime Wire)](https://runtimewire.com/article/openai-publishes-ai-generated-math-manuscripts)
- OpenAI followed advice from an advisory group at the **Institute for Advanced Study** and says it will fund workshops to review the results.

**Why it matters.** This is **AI as a research factory**, and Lean is what makes it checkable. For builders, the lesson travels: **pair a model with an automatic checker** (tests, type checks, proofs) and you can trust far more of its output.

Verified teams get **fewer safety blocks** for security work. [(Anthropic)](https://www.anthropic.com/news/cyber-verification-program) [(SiliconANGLE)](https://siliconangle.com/2026/10/06/anthropic-folds-project-glasswing-into-an-expanded-three-tier-cyber-verification-program/)

**The details that matter:**

- **Defense Access:** for incident response and malware analysis. **Open-source maintainers and individual researchers can apply**; Anthropic aims to answer within days.
- **Red Team Access:** adds authorised penetration testing, **organisations only**, reviewed over weeks. **Specialized Access**, for power grids and telecoms, is reviewed with the US government.
- **Track record:** Glasswing partners found **129,000+ verified vulnerabilities** from April to July; more than **33,000 were rated critical or high**, Anthropic says.

**Why it matters.** Models now find bugs at a scale humans can't. **The fight is over who gets the unlocked version**, and Anthropic is choosing vetting over a free-for-all.
