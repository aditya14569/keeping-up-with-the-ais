# Part 1 · Learn one thing

## 📍 Positional encodings: how models handle very long context

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 7 · NEWER TECHNIQUES</span>

**"Dog bites man" and "man bites dog" use the same three words. A model only knows which is news because of positional encodings.**

**The plain-English version.** A transformer looks at all the tokens at once, not left to right. On its own, **it has no idea which token came first**. So every model adds a signal that says "this token is at position 1, this one at position 2". How that signal is designed decides **how long a context the model can handle**, and how well it uses it.

**Analogy:** **seats in a cinema.** The original transformer gave every guest a **ticket with a seat number** (absolute position). That works until the hall gets bigger than the numbers printed on the tickets. Modern models instead teach each guest to **judge how far away their friends are sitting** (relative position). Distance still makes sense in a bigger hall.

```viz:versus
left: {emoji: 🎟️, title: Absolute position, points: ["Each slot gets its own fixed tag", "Learned or sine-wave patterns", "Breaks past the trained length"], example: "token + tag[position]"}
right: {emoji: 🔄, title: "Relative (RoPE)", points: ["Rotates each query and key by its position", "Attention sees only the gap", "Can be stretched to longer contexts"], example: "score depends on (i − j)"}
note: "Simplified. RoPE = rotary position embedding, used by Llama, Qwen and most open models."
```

**How RoPE works, in one line.** Each token's query and key vectors get **rotated by an angle that grows with position**. When two tokens are compared, the rotations cancel out except for **the gap between them**. So "3 tokens apart" looks the same at position 5 as at position 5,000. [(EleutherAI)](https://blog.eleuther.ai/rotary-embeddings/) [(RoFormer paper)](https://huggingface.co/papers/2104.09864)

**So how do you get to 1M tokens?** You train on shorter text, then **stretch the positions** with a little extra training:

| Method | The idea | The catch |
|---|---|---|
| **Sine-wave / learned tags** | The 2017 original: add a position pattern to each token | Struggles past its training length |
| **RoPE** | Rotate queries and keys; attention sees the gap | Still needs help beyond trained length |
| **ALiBi** | Penalise attention to faraway tokens, more with distance | Simple, but favours nearby text |
| **Position interpolation / YaRN** | Squeeze long positions into the range the model already knows, then fine-tune briefly | Can blur fine detail. YaRN tunes how [(YaRN paper)](https://arxiv.org/abs/2309.00071) |

**Fitting in isn't the same as reading.** The well-known "Lost in the Middle" study found models use facts **at the start or end of a long prompt** much better than facts **buried in the middle**. [(arXiv)](https://arxiv.org/abs/2307.03172) A 1M-token window is a promise of space, **not of attention**.

**Why now?** This week alone, Meituan's open **LongCat-2.5** and Meta's **Muse Ember** both advertise **1M-token context**. [(AI Weekly)](https://aiweekly.co/alerts/meituan-open-sources-longcat-25-16t-moe-under-mit-license) Ember also charges **three times as much** for prompts over 200K tokens. [(Meta)](https://research.meta.ai/blog/muse-ember) Long context is now a price tier, so knowing **when it actually helps** saves money.

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Positional encoding:** the signal added so a model knows token order.
- **RoPE:** rotary position embedding. Turns position into **an angle**, so attention sees relative distance.
- **Context extension:** stretching a model to longer inputs than it was mostly trained on, often with RoPE scaling like **YaRN**.
- **Needle in a haystack:** a test that hides one fact in a long text and asks the model to find it.
</div>

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** paste a long document (50+ pages) into any chatbot. Add one odd sentence **in the middle**, like "The office cat is named Pickle." Ask about it. Then move the sentence to page 1 and ask again. Did it notice both times?
- **Some code:** run the snippet below. It proves RoPE only cares about the gap.
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: RoPE in 12 lines**

```python
import numpy as np
def rope(v, pos, base=10000):
    out = v.copy(); d = len(v)
    for i in range(0, d, 2):
        t = pos * base ** (-i / d)
        out[i]   = v[i]*np.cos(t) - v[i+1]*np.sin(t)
        out[i+1] = v[i]*np.sin(t) + v[i+1]*np.cos(t)
    return out
rng = np.random.default_rng(0)
q, k = rng.normal(size=8), rng.normal(size=8)
for qp, kp in [(5, 2), (105, 102), (1005, 1002)]:
    print(qp, kp, round(float(rope(q, qp) @ rope(k, kp)), 4))
# Same score every time: the gap is 3 in all three
```

**Gotchas:** when self-hosting, the `rope_scaling` setting in a model's config is what turns long context on or off. **Static scaling can slightly hurt short prompts**, so only enable it when you need long inputs. And for RAG, **put the key passage first or last**, not in the middle.
</div>

- **[Rotary Embeddings: A Relative Revolution](https://blog.eleuther.ai/rotary-embeddings/)** (EleutherAI). The classic explainer, with the maths and pictures.

## Top story 3 · A breach at an AI host reaches Notion users

<span class="tag watch">SECURITY</span><span class="tag dev">FOR DEVS</span>

**What happened.** **Fireworks AI**, which runs open models for about **10,000 businesses**, confirmed a second breach. It reached billing records and, for some accounts, **secrets, customer datasets and unfinished model weights**. Notion says some **Notion AI chats** were exposed through it. [(AI Weekly)](https://aiweekly.co/ai-news-today)

<p style="break-after: avoid"><strong>The details that matter:</strong></p>

- **Timeline:** intrusion on **24 Oct**, customers told on **9 Nov**. Notion **cut Fireworks off on 3 Nov**, told users 6 Nov and confirmed the data on 8 Nov.
- **What Notion lost:** chat transcripts used for its Insights feature, from **under 1% of workspaces**, it says.
- **Type of attack:** investigated with Palo Alto's Unit 42 as **"LLMjacking"**, stealing access to run AI on someone else's account.
- **Fallout:** two customers told Forbes they **moved substantial business away**. [(The Neuron)](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-tuesday-november-10-2026/)

**Why it matters.** When you use an AI feature, your words may travel **through two or three companies** you've never heard of. **Your vendor's vendor is part of your attack surface.**
