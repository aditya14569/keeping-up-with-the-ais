# Part 1 · Learn one thing

## 🤖 AI agents: what they are and why everyone is launching one

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**A chatbot answers. An agent *acts*.**

Normal ChatGPT or Claude works like a vending machine: you put in a question, you get an answer, and it stops. An **agent** is the same kind of model put inside a *loop* and handed *tools*. You give it a **goal**, like "find three flights to Goa under ₹20k and put them in a sheet." It then keeps going on its own. It decides a step, does it, checks the result, and decides again, until the job is done or it needs you.

```viz:loop
title: The agent loop, the one idea behind every agent launch
center: Your goal
steps:
  - label: "1 · Think"
    sub: decide the next step
  - label: "2 · Act"
    sub: use a tool (search, code…)
  - label: "3 · Observe"
    sub: read what happened
  - label: "4 · Check"
    sub: done? stuck? ask you?
note: A chatbot does this once. An agent goes round this loop 5, 20 or 100 times until the goal is met.
```

**Analogy:** a chatbot is a smart friend you *call for advice*. An agent is an intern you *hand your laptop and logins to*. The intern gets far more done, but now it matters a lot what they're **allowed** to do.

### The five parts of every agent

| Part | What it is | Intern version |
|---|---|---|
| 🧠 **Model** | The LLM that thinks and decides | Their brain |
| 🧰 **Tools** | Search, browser, code, email, APIs | Laptop + apps |
| 🔁 **Loop** | Think → act → observe → repeat | Working a to-do list |
| 📓 **Memory** | What it remembers across steps and days | Their notebook |
| 🔐 **Permissions** | What it may do alone vs. ask first | "Ask before you pay for anything" |

OpenAI's dots, Meta's Muse, SpaceXAI's Grok Bot and Claude's agentic tools are all different recipes built from these same five parts. **To compare any two, ask:** which model? which tools? how long can it run? what does it remember? when does it stop and ask me?

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Tool call:** the model saying "run this function with these inputs." Your code runs it and hands back the result.
- **Context window:** how much text the model can "see" at once. Some models now handle around a million tokens, roughly a thick novel.
- **Prompt injection:** hidden instructions in a web page or file that try to hijack the agent reading it.
- **Human-in-the-loop:** the agent pauses and asks you before doing something important.
</div>

### Why now?

Three things came together in 2026. Models got reliable enough to handle **20+ steps** without wandering off. Context windows reached around **a million tokens**, so an agent can hold a whole project in its head. And companies started giving each agent **its own cloud computer**, so it keeps working while your laptop is closed. That last part is what "always-on" means in this week's headlines.

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** give any agent-capable assistant a *multi-step goal* instead of a question. For example: "Compare the three cheapest ways to deploy a small Next.js app, put them in a table, and pick one." Watch where it searches, where it reads, and where it changes its plan.
- **Some code:** run the tiny example agent from Unit 1 of the Hugging Face Agents Course (linked below).
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: the whole idea in ~10 lines**

```python
messages = [{"role": "user", "content": goal}]
for step in range(MAX_STEPS):              # always cap the loop
    reply = llm(messages, tools=TOOLS)      # model decides: answer or call a tool
    if not reply.tool_calls:
        return reply.text                   # done
    for call in reply.tool_calls:
        if call.name in NEEDS_APPROVAL and not ask_human(call):
            result = "User declined."
        else:
            result = run_tool(call)         # search, fetch, SQL, shell...
        messages.append(tool_result(call, result))
```

**What bites in production:** *runaway loops* (cap steps and spend), *prompt injection* (treat every tool output as untrusted data), *irreversible actions* (put sends, payments and deletes behind approval), and *cost* (every turn resends context, so use prompt caching). Start with the simplest fixed workflow that works. Only go fully autonomous when fixed steps can't do the job.
</div>

## Top story 1 · OpenAI launches "dots", always-on agents in ChatGPT

<span class="tag hot">BIG DEAL</span><span class="tag watch">PRO &amp; BUSINESS PREMIUM FIRST</span>

**What happened.** At DevDay 2026 in San Francisco on 29 September, OpenAI announced **dots**: personal agents inside ChatGPT, powered by its flagship GPT-6 Astra model. Each dot has **its own cloud computer**, works across the apps you connect, and keeps making progress *between* conversations. [(OpenAI Help Center)](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot) You can message it or call it in ChatGPT, or talk to it in **Slack and Teams**. Texting is "coming soon." [(The Next Web)](https://thenextweb.com/news/openai-dots-always-on-ai-agents-cloud-computers-devday)

**The details that matter:**

- **Who gets it:** ChatGPT **Pro and Business Premium** users in eligible markets, rolling out now, so some accounts may wait a few days. **One dot is included** at no extra cost. [(SiliconANGLE)](https://siliconangle.com/2026/09/29/openai-launches-dots-always-on-ai-agents-in-chatgpt-with-their-own-cloud-computers/) Enterprise, Edu and Healthcare get a beta once an admin enables it. [(OpenAI Help Center)](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot)
- **Usage:** chatting with your dot doesn't count toward ChatGPT limits, but tasks it starts in Codex or ChatGPT Work do. [(The Next Web)](https://thenextweb.com/news/openai-dots-always-on-ai-agents-cloud-computers-devday)
- **Safety rails:** dots have built-in rules for acting alone vs. asking, and you can override them with custom rules. They can log into sites with saved passwords **without the model ever seeing them**. [(DataCamp)](https://www.datacamp.com/blog/openai-dots)
- **Proactive mode:** with nothing to do, a dot goes looking for ways to help. OpenAI calls this "proactive research." [(SiliconANGLE)](https://siliconangle.com/2026/09/29/openai-launches-dots-always-on-ai-agents-in-chatgpt-with-their-own-cloud-computers/)

**Why it matters.** This is Part 1's agent, packaged for normal people. It also sets OpenAI directly against **Meta's Muse**, which launched in the US on 8 September and also runs on its own cloud computer. The race is no longer "whose chatbot is smartest." It's **"whose agent do you trust with your inbox?"** [(SiliconANGLE)](https://siliconangle.com/2026/09/29/openai-launches-dots-always-on-ai-agents-in-chatgpt-with-their-own-cloud-computers/)

## Top story 2 · Jev, the AI that refuses to talk

<span class="tag hot">DARK HORSE</span><span class="tag try">FREE TO TRY</span>

**What happened.** On 15 September, a startup called **TypeSafe AI** came out of stealth with **Jev** and a $40M seed round led by DCVC. The founder is Diogo Almeida, an ex-OpenAI researcher who worked on the techniques behind early ChatGPT. Jev is **deliberately not a chat model**. You give it some state (a support ticket, a log line, a game board) and a question with fixed answer options. It sends back a **pick, a probability and a confidence score**. No sentences. [(36Kr)](https://eu.36kr.com/en/p/3992394169613316) [(Digg, 85 sources)](https://digg.com/ai/skq6c9da)

```viz:versus
title: Same question, two kinds of AI
left:
  emoji: 💬
  title: Chat model (LLM)
  points:
    - Writes an answer word by word
    - Great for writing, reasoning, code
    - Overkill (slow and pricey) for tiny yes/no calls
  example: "\"This looks like a bug report, since the user mentions a crash after…\""
right:
  emoji: 🎯
  title: Decision model (Jev)
  points:
    - Returns a **typed pick + probability**
    - Answers in **70–500 ms**
    - Output tokens are **free**
  example: "bug       0.91\nfeature   0.06\nquestion  0.03"
note: The Jev output shown is an illustration of the format, not a real run. Speed and pricing are from TypeSafe via ThursdAI.
```

**The numbers.** TypeSafe calls Jev a **"System 1" model**, as in fast, gut-feel thinking. It has a 32K context window and costs **$42 per *billion* input tokens**, with output free. The company claims it's 133× faster and 444× cheaper than comparable LLMs on the decision tasks it tested. These are **the company's own numbers**, so wait for independent benchmarks. [(ThursdAI)](https://thursdai.news/companies/typesafe-ai) Since 21 September it has been **open to everyone** with a $5 starter credit. [(36Kr)](https://eu.36kr.com/en/p/3992394169613316)

**Why it matters.** Most AI apps use a huge, expensive model even for tiny calls like "is this spam?" or "which tool next?". Jev suggests a split: **a big model for thinking and writing, a tiny fast one for the hundreds of quick decisions in between.** Developers clearly liked the idea. Nearly 13% of Vercel's paid AI Gateway teams tried it within 24 hours, and it's already wired into Cloudflare, LangChain and Langfuse. [(36Kr)](https://eu.36kr.com/en/p/3997208294643586)

<div class="box devs" markdown="1">
**🛠️ For devs.** You define questions with three primitives, **choice**, **score** and **null**, and get machine-readable probabilities back. There's no free text to parse. The confidence score is the real feature: auto-act at 95%, send to a human at 55%. Try it anywhere you currently call an LLM just to classify something, and A/B the latency and cost.
