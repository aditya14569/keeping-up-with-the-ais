# Part 1 · Learn one thing

## 🗜️ Quantization: fitting big models on small hardware

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 5 · UNDER THE HOOD</span>

**Quantization stores each of a model's numbers with fewer bits, say 4 instead of 16. The model gets about four times smaller and usually faster, and if it's done well, barely any dumber.**

**The plain-English version.** A model is billions of numbers called **weights**. During training they're usually kept as 16-bit decimals (**FP16 or BF16**), so each weight takes 2 bytes. **A 70-billion-parameter model is therefore about 140 GB** before it has read a single word. That's more than any laptop GPU.

**Quantization rounds those weights onto a small grid of allowed values.** With 8 bits there are 256 steps; with 4 bits, only 16. You also store a **scale** that says how big one step is, so you can turn the small integers back into roughly the right decimals when the model runs.

**Analogy:** **a thali photo sent over WhatsApp.** The original from your phone is 12 MB. WhatsApp squeezes it to a few hundred KB. **Zoom in and you'll find fuzzy edges, but your friend can still tell it's dal, rice and two rotis.** Quantization is the same deal: lose the fine detail nobody needed, keep the picture.

**A real example, from yesterday.** Simon Willison ran **Qwen 3.8 27B in the `Q4_K_M` format** (a popular 4-bit GGUF file) on his laptop with LM Studio. By our maths, that model needs about 54 GB at 16 bits but **around 16 GB at Q4_K_M** (which averages a bit under 5 bits per weight). It then read the raw weights of small game-playing networks and named three of four correctly. [(AI Weekly)](https://aiweekly.co/alerts/willison-qwen-38-27b-names-3-of-4-game-nets-on-laptop)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Precision / bits:** how many bits store each number. **Fewer bits, smaller model**, rougher numbers.
- **Scale:** the multiplier that turns small integers back into **approximately the original** decimals.
- **GGUF:** the file format used by llama.cpp, Ollama and LM Studio. Names like **Q4_K_M or Q8_0** tell you the bits.
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: quantize by hand, then for real**

```python
import numpy as np
np.random.seed(0)
w = np.random.randn(8).astype(np.float32) * 0.5
def quantize(w, bits):
    qmax = 2 ** (bits - 1) - 1              # 4 bits -> 7
    scale = np.abs(w).max() / qmax          # one scale per block
    q = np.round(w / scale).clip(-qmax, qmax).astype(int)
    return q, q * scale                      # ints to store, values to use
for bits in (8, 4):
    q, back = quantize(w, bits)
    print(bits, q, "max error", np.abs(w - back).max().round(4))
# 8 [100 23 55 127 106 -55 54 -9] max error 0.0041
# 4 [6 1 3 7 6 -3 3 0]             max error 0.0784
```

**Gotchas:** 4-bit is the usual sweet spot; **below 3 bits quality often falls off a cliff**, and maths and code suffer first. Run your evals (Issue #26) before and after. For real models, Hugging Face's `BitsAndBytesConfig(load_in_4bit=True)` does this for you.
</div>

## Top story 1 · Postman quietly plugged itself into Claude Code and Codex

<span class="tag hot">BIG DEAL</span><span class="tag dev">FOR DEVS</span>

**What happened.** A developer reports that opening **Postman desktop 12.33.4** silently installed Postman plugins into **Codex and Claude Code**, with no prompt. The GitHub issue reached **#2 on Hacker News** yesterday, and Postman **hasn't responded publicly**. [(AI Weekly)](https://aiweekly.co/alerts/postman-desktop-silently-installs-plugins-into-codex-claude-code) [(GitHub)](https://github.com/postmanlabs/postman-app-support/issues/14370)

**The details that matter:**

- **What it touched (macOS):** `~/.codex/config.toml`, `~/.claude/settings.json`, `~/.claude/plugins/installed_plugins.json`, plus a Postman program in `~/.local/bin`. It also pointed both agents at **Postman's MCP server**.
- **The worrying bit:** an installer function called `approvePostmanHook` **wrote the hook's trust record itself**. Those trust checks exist so that *you* approve code that runs when your agent starts.
- **What the hook says:** it tells the agent to load Postman's `api-engineer` skill before **any non-trivial API task**, not just ones that mention Postman.
- **Not yet confirmed independently:** nobody has reproduced it on a clean machine so far. The reporter asks for **opt-in installs and no self-approval**.

**Why it matters.** Your coding agent's config folder is now **valuable real estate**, and apps are starting to fight over it. A hook that runs on every session is **a supply-chain risk** (Issue #32's trojanized extension was the extreme case).

## Top story 2 · Anthropic's FlashProve: a receipt that proves which model answered

<span class="tag learn">RESEARCH</span><span class="tag watch">TRUST</span>

**What happened.** Anthropic, with **EPFL, MIT, StarkWare and Succinct**, released **FlashProve** under the Apache 2.0 licence. It produces a **zero-knowledge proof** that a reply came from one specific, committed set of weights, **without revealing the weights**. [(AI Weekly)](https://aiweekly.co/alerts/anthropic-opens-flashprove-with-epfl-and-mit-cryptographically-verifying-ai) [(Anthropic)](https://www.anthropic.com/research/provable-inference)

**The details that matter:**

- **Speed:** proofs generate at **over 100 tokens per second** on one H100, but the prover is **72 to 94 times slower** than serving the same model normally with vLLM.
- **Narrow for now:** replies up to **1,024 tokens**, integer (quantized) models only, and **greedy decoding** (always picking the top word, so no temperature).
- **Checked by maths, too:** its three security guarantees were **formally verified in Lean**, a proof-checking language.
- **A promise kept:** Anthropic's safety roadmap aimed for a **provable-inference prototype by 30 September 2026**.

**Why it matters.** Today you **trust** that "Model X" on some API really is Model X and not a cheaper swap. FlashProve hints at a future where **you can check**. That matters for audits, regulated industries and anyone reselling models.
