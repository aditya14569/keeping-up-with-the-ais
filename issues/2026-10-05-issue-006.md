# Part 1 · Learn one thing

## 🧠 Reasoning models and the "effort" dial

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 1 · HOW LLMS WORK</span>

**A reasoning model thinks before it talks. The effort dial decides for how long, and you pay for every word of thinking you never see.**

An ordinary chat model starts writing the answer straight away. A **reasoning model** first writes hidden **reasoning tokens**: it plans, tries an approach, checks it and backtracks. Then it writes the reply. OpenAI says these tokens **take up context space and are billed as output tokens**, even though the API doesn't show them. [(OpenAI)](https://developers.openai.com/api/docs/guides/reasoning)

**Effort** is how much of that thinking you allow. On Claude it covers **the whole response**, not just the thinking. Low effort means **fewer tool calls and shorter replies**, and it can skip thinking on easy questions. High effort means more planning and more checking. [(Claude Docs)](https://platform.claude.com/docs/en/build-with-claude/effort)

**Analogy:** think of the **rough-work column in a maths board exam**. The examiner marks the final answer, but the rough work is where you get it right. On a two-mark sum you barely use it. On a ten-mark proof you fill the page. **Effort is how much rough paper you hand the model**, and here every sheet is billed.

### More thinking isn't always better

Here's one data-analysis benchmark run at every effort level on OpenAI's GPT-6 Astra. **Cost per task goes up 2.5 times. The score doesn't move.** Low and Max both score 55.0. [(AI Agent Store)](https://aiagentstore.ai/ai-models/reasoning-effort/gpt-6-astra)

A Lenovo study found the same pattern. **Thinking pays off on step-by-step problems like maths contests, but much less on knowledge questions.** In reasoning runs, a median **94.7% of generated-token spend went on thinking**. Going from high to max effort sometimes **lowered accuracy**. [(arXiv)](https://arxiv.org/pdf/2608.26235)

The upside is real too. Hugging Face showed a **3B model, given time to search through answers, beating a 70B model** on a maths test. **Thinking longer can beat being bigger.** [(Hugging Face)](https://huggingfaceh4-blogpost-scaling-test-time-compute.hf.space/)

**Why now?** In the last week, the Gemini app got low, medium and high effort, and Copilot code review got an effort setting (Issue #5). **Every major API now has this dial:**

| API | Parameter | Levels | Default |
|---|---|---|---|
| **OpenAI** | `reasoning.effort` | none → max (varies by model) | medium on gpt-5.5 |
| **Claude** | `output_config.effort` | low, medium, high, xhigh, max | high; medium on Opus 5.5 |
| **Gemini** | `thinking_level` | minimal, low, medium, high | medium on 3.8 Flash |

Sources: [(OpenAI)](https://developers.openai.com/api/docs/guides/reasoning) [(Claude Docs)](https://platform.claude.com/docs/en/build-with-claude/effort) [(Gemini API)](https://ai.google.dev/gemini-api/docs/thinking)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Reasoning tokens:** the model's hidden scratchpad. You pay for them but don't see them.
- **Effort / thinking level:** a setting for how much work the model puts into a reply.
- **Test-time compute:** spending more computing power when answering, not during training.
- **Thinking summary:** a short, readable recap of the hidden reasoning that some APIs can return.
</div>

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** in ChatGPT or Gemini, ask the same two things in the quick mode and the thinking mode: "What's the capital of Kerala?" and "I have ₹500. Samosas cost ₹15 and chai ₹12. What's the most snacks I can buy with at least 3 chai?" **Note which one actually needed the thinking.**
- **Some code:** run one prompt at two effort levels and print how many hidden tokens you paid for: [(OpenAI)](https://developers.openai.com/api/docs/guides/reasoning)

```python
for effort in ["low", "high"]:
    r = client.responses.create(
        model="gpt-6-astra",
        reasoning={"effort": effort},
        input=puzzle)
    u = r.usage
    print(effort, u.output_tokens_details.reasoning_tokens)
```
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: tune effort like any other setting**

- **Start low and go up only when your evals improve.** The Astra chart above is the reason.
- **Leave room.** OpenAI suggests reserving **at least 25,000 tokens** for reasoning plus output when you start out. [(OpenAI)](https://developers.openai.com/api/docs/guides/reasoning)
- **Use low effort for subagents and simple tool steps.** Claude's effort also changes **how many tool calls** the model makes. [(Claude Docs)](https://platform.claude.com/docs/en/build-with-claude/effort)
- **Changing effort mid-chat?** Claude has a beta that lets you switch it per message **without breaking the prompt cache**.

**Gotcha:** if thinking uses up `max_output_tokens`, OpenAI returns `status: incomplete` with **no visible answer at all**. Always check the status before you show the user the output.
</div>

## Top story 2 · An AI found the bug. Attackers used it within a day

<span class="tag hot">PATCH NOW</span><span class="tag dev">DEVS · SECURITY</span>

**What happened.** **CVE-2026-61500** is a critical flaw in **Rejetto HTTP File Server (HFS)**, an open-source file server. Security firm Horizon3 found it using Anthropic's **Mythos** model. Horizon3 disclosed it on Wednesday, 30 September. **The next day**, VulnCheck saw a China-hosted IP address attacking servers in the US and Japan. [(The Register)](https://www.theregister.com/security/2026/10/03/anthropics-super-bug-hunting-model-mythos-is-hardcore-good-at-math-as-latest-vuln-under-attack-shows/5300933)

```viz:flow

      sub: signs sessions
      style: warn

      sub: runs commands

```

**The details that matter:**

- **The bug:** HFS signed login sessions with a key from JavaScript's `Math.random()`, which **isn't built for secrets**. A separate code path leaked its outputs. **Mythos spotted both and saw how they fit together.** [(The Register)](https://www.theregister.com/security/2026/10/03/anthropics-super-bug-hunting-model-mythos-is-hardcore-good-at-math-as-latest-vuln-under-attack-shows/5300933) [(Superpower Daily)](https://superpowerdaily.com/posts/horizon3-says-anthropic-s-mythos-turned-a-file-server-flaw-into-a-working-exploit)
- **The fix:** update to **HFS 3.2.1 or later**. More attack attempts followed on Friday, from US addresses that looked like proxies.
- **Before this, only 1 of the 286 bugs** credited to Mythos and Project Glasswing had been exploited in the wild.
- **The flip side:** Google **stopped taking product bug reports** for its open-source bug bounty on 1 October. Engineers were drowning in **AI-written reports for bugs that weren't real**. Supply-chain reports are still open, and Google promises an update by Q1 2027. [(Tom's Hardware via Yahoo)](https://tech.yahoo.com/ai/articles/google-freezes-open-source-bug-120000127.html)

**Why it matters.** AI now finds real bugs fast, and **attackers read the same disclosures**. The time you have to patch is shrinking to hours. Meanwhile, **bad AI bug hunting is wasting maintainers' time**, which is yesterday's hallucination lesson in real life.

**🛠️ For devs: what to check this morning**

- **Running HFS anywhere?** Upgrade to **3.2.1+** or take it offline. [(The Register)](https://www.theregister.com/security/2026/10/03/anthropics-super-bug-hunting-model-mythos-is-hardcore-good-at-math-as-latest-vuln-under-attack-shows/5300933)
- **Search your code for `Math.random()` near tokens, sessions or IDs.** Use `crypto.getRandomValues()` or `crypto.randomUUID()` in JS, and `secrets` in Python.
- **Using AI to hunt bugs?** **Reproduce every finding before you report it.** A report you can't reproduce is spam.

**What happened.** Security researcher **Karan Joshi** got Meta's **Muse** agent to share its own internal files just by asking in chat. Wired reported that they tell Muse to keep **a page on every contact in your life**: family, partners, friends and colleagues. **An hourly job keeps the pages up to date.** [(Archyde)](https://www.archyde.com/metas-ai-assistant-muse-creates-detailed-profiles-of-friends-and-family/)

[(TechSpot)](https://techspot.com/news/114091-florida-woman-used-claude-diary-anthropic-reported-shoot.html)

**Why it matters.** **A chat with an AI isn't a private notebook.** Agents are built to remember the people around you, and companies keep the right to act on what you write.
