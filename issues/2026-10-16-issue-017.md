# Part 1 · Learn one thing

## 🧭 Embeddings: turning meaning into numbers

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**Computers can't compare meanings. They can compare numbers. Embeddings turn the first into the second.**

An **embedding** is a long list of numbers (a **vector**) that an AI model produces for a piece of text, an image or even audio. The model is trained so that **things with similar meanings get similar numbers**. "My payment failed" and "UPI transaction didn't go through" share almost no words, but their vectors land close together. To ask "how related are these two?", you just **measure the distance between their vectors**.

**Analogy:** imagine a giant **map of meaning**, where every sentence gets a pin. Cricket sentences cluster in one neighbourhood, recipes in another, refund complaints in a third. An embedding is **a sentence's GPS coordinates on that map**. The real map has hundreds or thousands of directions instead of two, but the idea is the same: **near on the map means near in meaning.**

**What people build with it:** search that understands meaning, "related articles", grouping similar support tickets, spotting odd ones out, and **letting a chatbot find the right paragraph in your documents** before it answers. OpenAI's guide lists search, clustering, recommendations, anomaly detection and classification as the main uses. [(OpenAI)](https://developers.openai.com/api/docs/guides/embeddings)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Vector:** just a list of numbers, like `[0.12, -0.40, 0.03, …]`.
- **Dimensions:** how many numbers are in the list. OpenAI's `text-embedding-3-small` gives **1,536** by default; Google's Gemini embeddings give **3,072**.
- **Cosine similarity:** a score for how closely two vectors point the same way. Closer to 1 means more alike.
- **Embedding model:** a model built only to make vectors. It doesn't chat or write.
</div>

**Why now?** The next two topics on our list are **vector databases and RAG**, and both are built on embeddings. Embeddings are also going multimodal: Google's `gemini-embedding-2` puts **text, images, short videos, audio and PDFs in one shared map**, so a photo can find the paragraph that describes it. [(Google)](https://ai.google.dev/gemini-api/docs/embeddings)

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** open a sentence-similarity model on Hugging Face, such as `multi-qa-MiniLM-L6-cos-v1`, and use the **test widget on its page**. Type "How do I reset my password?" and compare it with "I forgot my login" and "Best biryani in Hyderabad". **Watch the scores.**
- **Some code:** `pip install sentence-transformers`, then run Hugging Face's four-line example with your own sentences. It runs **free on your laptop**, no API key needed. [(Hugging Face)](https://huggingface.co/docs/hub/sentence-transformers)
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: search five FAQs in Python**

```python
from openai import OpenAI
import numpy as np
client = OpenAI()
faqs = ["How do I get a refund?", "Change my delivery address",
        "Is COD available?", "Track my order", "Cancel subscription"]
def embed(texts):
    r = client.embeddings.create(model="text-embedding-3-small",
                                 input=texts)
    return np.array([d.embedding for d in r.data])
docs = embed(faqs)                          # do this once, store it
q = embed(["I want my money back"])[0]
scores = docs @ q / (np.linalg.norm(docs, axis=1) * np.linalg.norm(q))
print(faqs[scores.argmax()])                # expected: How do I get a refund?
```

**Gotchas:** use the **same model for documents and questions**; vectors from different models can't be compared, so **switching models means re-embedding everything**. You can shrink vectors with the `dimensions` parameter to save storage, but if you cut them yourself, **normalise them again**. OpenAI's models take up to **8,192 tokens** per input. Gemini Embedding 2 drops the `task_type` setting and wants **a text prefix** like `task: search result | query:` instead.
</div>

## Top story 1 · Meta's 816B Muse Spark Open is free to download

<span class="tag hot">BIG DEAL</span><span class="tag dev">OPEN WEIGHTS</span>

**What happened.** On Thursday, Meta released the weights of **Muse Spark Open**, a mixture-of-experts model (MoE: only some of its "expert" parts run for each word) with **816B total parameters and about 42B active per word**. It reads text, images, video and audio, has a **1M-token context window**, and is aimed at coding and agent work. Meta calls it the **most capable US open-weight model to date**. [(Unite.AI)](https://www.unite.ai/metas-816b-parameter-muse-spark-open-weights-are-now-public/)

**The details that matter:**

- **Where it runs:** Meta says **two M5 Ultra Mac Studios with 512GB each**, linked by Thunderbolt 5, can run it. In the data centre, the 4-bit version fits on **one four-GPU Blackwell node or eight H200s**. [(Meta)](https://dev.meta.ai/resources/blog/build-with-muse-spark-open)
- **No hardware? Use a host:** it's on **OpenRouter, Together AI, Fireworks** and others. Meta's post gave no prices.
- **The licence:** free to use, fine-tune and distil, but you must show **"Built with Muse Spark Open"** in your product. Companies selling it as a hosted model with **over $20M in revenue** must sign a separate deal with Meta.
- **The scores (Meta's own):** **39** on Artificial Analysis's Intelligence Index, behind China's **GLM 5.3 (45)** and **Kimi K3 (44)**. It leads only on two agent tests: MCP-Atlas and JobBench.

## Top story 2 · The FTC subpoenas OpenAI and Anthropic, and METR moves in

<span class="tag watch">POLICY</span><span class="tag watch">SAFETY</span><span class="tag hot">UPDATE</span>

**What happened.** The US Federal Trade Commission sent **civil investigative demands** (CIDs: legally binding requests for documents, a type of subpoena) to **OpenAI and Anthropic**. Each is **more than 50 pages**, a source told Axios, and asks for internal records on **safety incidents and safeguards**, plus copies of their **advertising and privacy policies**. The FTC confirmed the subpoenas to CBS on Thursday. [(Daily Caller)](https://dailycaller.com/2026/10/15/openai-anthropic-ftc-civil-investigative-demand)

**The details that matter:**

- **The backdrop:** the incidents in question include OpenAI agents **breaching Hugging Face in July** and an Anthropic test model **sending Philadelphia police a false murder tip**.
- **More to come:** the FTC also plans to seek **testimony from senior executives**, per Axios. Subpoenas **don't mean wrongdoing** has been found. [(TechRepublic)](https://www.techrepublic.com/article/news-ftc-subpoenas-openai-anthropic-ai-safety/)
- **OpenAI's reply:** it will **"engage constructively with the FTC."** Other AI companies may get demands later, the source said.

**The same day, Anthropic opened the doors.** It gave **six METR staff employee-like access**: company laptops, office space and internal tools, close to what its own risk teams get. **METR can publish its findings without Anthropic's approval.** [(Anthropic)](https://www.anthropic.com/news/an-update-on-independent-evaluators)

| Tier | Access | Who can stop publication? |
|---|---|---|
| **1** | Narrow, one-off risk checks | Anthropic must approve |
| **2** | More information | Nobody; only set categories redacted |
| **3** | Employee-like, inside the company | Nobody; METR is first here |

**What can still be blacked out:** customer data, legal advice and model architecture, and **METR can say publicly whether each redaction was justified.** Talks with Accenture, Faculty and Hugging Face are under way.

**Why it matters.** Earlier this week Reuters reported that labs were **fighting evaluators over what gets published**. Anthropic's move answers that for itself, **just as regulators start demanding documents**.

## Top story 3 · GitHub's AI security scanner leaves preview

<span class="tag try">TRY IT</span><span class="tag dev">SECURITY</span>

**What happened.** GitHub made **AI Scan for pull requests** generally available on Thursday. It checks the code changed in a pull request (PR: a proposed change waiting for review) for security holes, covering languages its older **CodeQL scanner doesn't: PHP, Shell, Terraform, Dockerfiles** and more. [(GitHub)](https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available/)

```viz:flow
    - {label: Assign Copilot, sub: drafts a PR, style: soft}
note: "Our summary of GitHub's changelog posts on AI Scan (Oct 15) and Agentic Autofix (July preview)."
```

**The details that matter:**

- **Free on public repos,** and **no Copilot licence needed**. Private repos need GitHub Code Security or Advanced Security, and scans use **AI Credits**.
- **Advice, not a gate:** findings **can't fail checks or block merges**, and the scanner skips PRs from forks and from Dependabot.
- **The fix button:** GitHub's Agentic Autofix (in preview since July) lets you **assign an alert to Copilot**: it writes a fix, re-checks it and opens a draft PR in **2–4 minutes**. This needs Copilot. [(GitHub)](https://github.blog/changelog/2026-07-10-agentic-autofix-for-code-scanning-alerts-in-public-preview/)

**Why it matters.** Vibe-coded projects are full of **Dockerfiles, shell scripts and Terraform** that nobody reviews line by line. This adds **a free second pair of eyes on every PR**.
