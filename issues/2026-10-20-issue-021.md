# Part 1 · Learn one thing

## 🧰 Skills: teaching your AI a job once

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**MCP (yesterday) gives an AI new hands. A skill gives it know-how: the steps to do one job your way.**

A **skill** is just **a folder with a `SKILL.md` file inside**. At the top sit a `name` and a one-line `description`. Below that are plain-English instructions, plus any scripts, templates or reference files the job needs. **When your request matches the description, the AI opens the folder and follows it.** [(Agent Skills)](https://agentskills.io/home)

**Analogy:** **a recipe binder in a restaurant kitchen.** The chef doesn't memorise every recipe. They see the tabs on the binder, and **pull out the right card only when that dish is ordered.** Anthropic's own comparison is an **onboarding guide for a new hire**. [(Anthropic)](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)

```viz:flow
title: How a skill loads (only what's needed)
headers: [At startup, You ask, Skill opens, Only if needed]
columns:
  - - {label: Names + blurbs, sub: ~100 tokens each}
  - - {label: Match found, sub: "via description", style: accent}
  - - {label: Read SKILL.md, sub: under 5k tokens}
  - - {label: Extra files, sub: loaded on demand, style: soft}
    - {label: Scripts, sub: only output counts, style: soft}
note: "Token figures from Anthropic's Agent Skills docs. This staged loading is called 'progressive disclosure'."
```

**Why that matters:** you can install **dozens of skills and pay almost nothing** until one is used. Scripts are even cheaper: the AI **runs them, and only their output enters its memory**, not the code. [(Claude Docs)](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **SKILL.md:** the one required file. **Frontmatter** (the bit between `---` lines) holds `name` and `description`; the rest is instructions.
- **Progressive disclosure:** load **labels first, details later**, so many skills fit in a small context window.
- **Plugin:** an installable **bundle of skills, MCP servers and commands**. In Claude Code its skills show up as `/plugin-name:skill-name`.
- **CLAUDE.md / AGENTS.md:** instructions loaded **every turn**. Facts go there; **step-by-step procedures go in skills**.
</div>

**Why now?** Anthropic released the format as an **open standard**, and agentskills.io now lists **more than 40 tools** that read it, including **ChatGPT and Codex, Cursor, Gemini CLI, GitHub Copilot and Mistral Vibe**. [(Agent Skills)](https://agentskills.io/home) One folder, every app.

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** write a one-page "how I want it done" note for a task you repeat (your weekly update, a client email). Start with one line: **"Use this when…"**. That note is a skill. On Claude's paid plans you can **upload it as a zip** under Settings › Features.
- **Some code:** in any repo, create `.claude/skills/commit-msg/SKILL.md` with the example below. Open Claude Code and type **`/commit-msg`**. Then make a change and just say "commit this", and **watch it pick the skill up by itself**.
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: a skill in 9 lines**

```markdown
---
name: commit-msg
description: Write git commit messages in our style. Use when committing or when asked for a commit message.
---
1. Run `git diff --staged` and read it.
2. Subject: imperative, max 60 chars, prefix feat|fix|chore.
3. Body: why, not what. Wrap at 72 chars.
```

**Gotchas:** **the description is the trigger**, so say what it does *and* when to use it. Names are **lowercase-with-hyphens, max 64 characters**. For anything with side effects (deploys), add **`disable-model-invocation: true`** so only you can start it. [(Claude Code docs)](https://code.claude.com/docs/en/skills.md) And **treat skills like software you install**: Snyk scanned 3,984 public skills and found **13.4% with a critical issue and 76 confirmed malicious payloads**. [(Snyk)](https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub)
</div>

## Top story 1 · One hacker, 1,200 targets, about $50 a break-in

<span class="tag hot">BIG DEAL</span><span class="tag watch">SECURITY</span><span class="tag dev">AGENTS</span>

**What happened.** Snorre Fagerland, a researcher at security firm **NorForge**, found a Chinese-speaking hacker running **AI agents that tried to break into more than 1,200 shop websites** in the US, Canada, Australia and Japan. Reuters says they **got into sites of more than 100 companies**, including **Deere, SharkNinja and Cummins**. [(Reuters via CP24)](https://www.cp24.com/news/world/2026/10/19/how-one-hacker-used-ai-agents-and-a-few-thousand-dollars-to-break-into-scores-of-sites-reuters-exclusive/)

**The details that matter:**

- **The tool:** **Cairn**, an open-source platform where agents work towards a goal and **share findings on a common board**. One worker was named `claudecode_deepseek-v4.1-flash`, which NorForge reads as **Claude Code running DeepSeek's cheap model**. [(TNW)](https://thenextweb.com/news/ai-agents-hacker-cairn-100-sites-deere-norforge)
- **Barely any human:** the hacker's instructions were **under 100 Chinese characters**. A typical break-in took **about 23 hours** of automated probing.
- **The cost:** **roughly $5,000 in tokens, about $50 per success**, Fagerland estimates. NorForge's report puts it at about **$5 per task**, failures included.
- **How it was caught:** operators **left Cairn control panels open on the internet**. Those panels also held **hundreds of credentials and API keys**; 11% were still valid. [(TNW)](https://thenextweb.com/news/ai-agents-hacker-cairn-100-sites-deere-norforge)
- **Responses:** Deere says no sign sensitive data was accessed; SharkNinja says only a standalone support site was hit; Cummins is investigating. **Reuters couldn't tell how much data was taken.**

**Why it matters.** Breaking into a website used to need a skilled person's time. Now **patience is cheap: an agent will try for 23 hours without getting bored.** Small sites that thought "no one would bother with us" are exactly who gets hit.

**🛠️ For devs: three things to check today**

**Never expose an agent dashboard** to the open internet without login. **Keep keys out of agent logs** and rotate any that leaked. And **patch admin panels and side services**: the agents found their way in through a linked control panel when the main app had no holes.

## Top story 2 · Mercury 3: a model that writes the whole draft at once

<span class="tag try">TRY IT</span><span class="tag dev">API</span><span class="tag hot">SPEED</span>

**What happened.** Inception launched **Mercury 3**, a **diffusion** language model. It claims **over 1,000 tokens a second** on ordinary Nvidia GPUs, a **1M-token context window** (up from 260K) and wins over **GPT-6 Luna and Claude Haiku 5.5** on several benchmarks. [(Business Wire via Yahoo)](https://finance.yahoo.com/technology/ai/articles/inception-launches-mercury-3-setting-164800350.html)

```viz:versus
title: Two ways to write an answer
left:
  emoji: ➡️
  title: Normal LLM
  points:
    - Writes one token at a time
    - Each word waits for the last
    - Speed capped by that chain
  example: "The → cat → sat → ..."
right:
  emoji: 🌫️
  title: Diffusion LLM
  points:
    - Drafts many tokens at once
    - Refines the draft in a few passes
    - Much faster per answer
  example: "[▒▒▒ ▒▒▒ ▒▒▒] → The cat sat"
note: "Simplified illustration of how Startup Fortune and Interesting Engineering describe diffusion models."
```

**The details that matter:**

- **Price:** list **$0.20 in / $0.70 out per million tokens**, with **50% off at launch** ($0.10 / $0.35) and 90% off cached input. **No end date** for the discount is given.
- **Where:** Inception's API, **OpenRouter, Baseten and Vercel**. It speaks the **OpenAI API format**, so switching is a few lines.
- **Speed claim:** **4–8× faster** than GPT-6 Luna and Haiku 5.5, per Inception. [(Interesting Engineering)](https://interestingengineering.com/ai-robotics/mercury-3-diffusion-model-8-times-faster)
- **The catch:** benchmark wins are named (IFBench, GPQA Diamond, SWE-Bench Atlas) but **scores weren't published**, and **no independent tester has checked them yet**. [(Startup Fortune)](https://startupfortune.com/inception-labs-claims-mercury-3-beats-haiku-and-gpt-6-luna-at-1068-tokens-a-second/)

**Why it matters.** For chat, voice and agents, **waiting is the thing users feel**. A model that is "good enough" and answers in a second can beat a smarter one that takes ten.

## Top story 3 · OpenAI: GPT-6 learns COBOL

<span class="tag dev">CODING</span><span class="tag watch">LEGACY CODE</span>

**What happened.** OpenAI says its newest models are much better at **"low-resource" languages**: ones with little code online to learn from, like **COBOL, Fortran, Visual Basic and OCaml**. It published a new test, **MultiLangBench**, on GitHub. [(OpenAI)](https://openai.com/index/low-resource-programming-languages/)

```viz:bars
  - {label: OCaml · GPT-6 Astra, value: 85.8, display: "85.8%", highlight: true}
note: "OpenAI's own MultiLangBench results. Not independently verified."
```

**The details that matter:**

- **The test:** build a **SQLite-compatible database engine** in each of **20 languages**. GPT-6 Astra averages **87.4% of tests passed**, against 26.8% for GPT-5.6 Sol.
- **Migration:** moving COBOL to Java, Python, Rust and others, **GPT-6.1 Sol hit 86.6% at low effort** (vs 5.4% before) and **97.9% at higher effort**.
- **Budget option:** **GPT-6 Luna averages 40.3%** at about **$0.77 per attempt**, versus $3.48 for GPT-5.6 Sol.
- OpenAI itself says **real migrations still need expert review and testing**. [(OpenAI)](https://openai.com/index/low-resource-programming-languages/)

**Why it matters.** Banks, insurers and governments still run on **decades-old COBOL**, and the people who know it are retiring. Mainframe migration is also **big business for Indian IT services firms**. If these numbers hold, that work gets faster, and the jobs in it change shape.
