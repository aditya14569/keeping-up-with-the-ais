# Part 1 · Learn one thing

## 👥 Multi-agent systems and orchestration

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**Yesterday: one agent in a loop. Today: a team of agents, with a boss.**

A multi-agent system is **one "lead" agent that splits a job and hands pieces to "sub-agents"**. Each sub-agent works in **its own fresh context window**, then **sends back a short summary**. The lead combines the summaries and decides what to do next. [(Anthropic Engineering)](https://www.anthropic.com/engineering/multi-agent-research-system)

**Analogy:** **a newsroom.** The editor sends four reporters to four places. Each comes back with **one page of notes, not their whole notebook**. The editor writes the story. It works because **the reporters gather and only the editor writes**. Four reporters writing the same article at once would be a mess.

**Does it actually help?** Anthropic's research setup (an Opus lead with Sonnet sub-agents) **beat a single Opus agent by 90.2%** on its internal eval. Parallel work cut research time **by up to 90%** on hard queries. The catch: **about 15× the tokens of a chat**. [(Anthropic Engineering)](https://www.anthropic.com/engineering/multi-agent-research-system)

**And when does it break?** Devin maker Cognition's classic example: split "build Flappy Bird" between two sub-agents and one draws **a Mario-style background**, while the other makes **a bird that doesn't fit the game**. **Each made its own hidden choices.** [(Cognition)](https://cognition.com/blog/dont-build-multi-agents)

```viz:versus

```

**Four patterns you'll meet.** Notice the middle column: **in every pattern that works, one agent holds the pen.** [(Cognition)](https://cognition.com/blog/multi-agents-working)

| Pattern | Who writes | Example |
|---|---|---|
| **Orchestrator-worker** | The lead only | Anthropic's research mode |
| **Reviewer loop** | The coder only | Devin + Devin Review (claims ~2 bugs caught per PR) |
| **Smart friend** | The small model | A cheap model asks a big one for hard calls |
| **Handoff** | One agent at a time | A support bot passing you from triage to billing |

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Orchestrator (lead agent):** the agent that **plans, hands out work and merges results**.
- **Sub-agent:** a helper with **its own context window**. It sees only the brief you give it.
- **Handoff:** passing the conversation **to a different agent** (say, from triage to billing).
- **Single-threaded writes:** **only one agent changes files**; the others read, search or review.
</div>

**Why now?** On Wednesday Microsoft Research described how two researchers proved **a 31-year-old maths conjecture (KLS)**. Many AI agents explored ideas **in parallel**, a human **pruned the dead ends**, and about **100 attempts** ran before the breakthrough. The same models working alone **fell short**. [(Microsoft Research)](https://www.microsoft.com/en-us/research/blog/solving-a-31-year-old-grand-challenge-in-mathematics-the-kls-conjecture/) The flip side is in Quick hits: **an OpenAI agent told a sub-agent to switch off safety alerts.**

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** open two chats. In chat 1, ask for a plan for your app idea. Paste it into chat 2 with **"You're a sceptical reviewer. List the 5 biggest holes."** That's **the reviewer pattern by hand**, and the clean second chat is the point.
- **Some code:** in Claude Code, add `.claude/agents/reviewer.md` with **read-only tools** (`Read, Grep, Glob`). Ask Claude to "use the reviewer on my last change". **It reviews in its own context and reports back.** [(Claude Code Docs)](https://code.claude.com/docs/en/sub-agents)
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: fan out, then fan in**

```python
import asyncio
async def sub_agent(brief):
    r = await client.messages.create(model=SMALL, max_tokens=2000,
        system="Research only. Reply in <=300 words with sources.",
        messages=[{"role": "user", "content": brief}])
    return r.content[0].text

async def lead(question, briefs):          # briefs come from a planning call
    notes = await asyncio.gather(*[sub_agent(b) for b in briefs])
    return await client.messages.create(model=BIG, max_tokens=4000,
        messages=[{"role": "user",
                   "content": question + "\n\nNotes:\n" + "\n---\n".join(notes)}])
```

**Gotchas:** each brief needs **a goal, an output format and clear limits**, or sub-agents duplicate work. Anthropic's early version **started 50 sub-agents for simple questions**. **Keep writes in one agent.** In Claude Code, sub-agents can nest **three levels deep** by default; set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to stop that.
</div>

## Top story 1 · PHP2Shell: AI found a hole in most of the web

<span class="tag hot">BIG DEAL</span><span class="tag watch">SECURITY</span><span class="tag dev">PATCH NOW</span>

**What happened.** PHP shipped emergency fixes for **two critical bugs (CVE-2026-109618 and -109619, each rated 9.2 out of 10)**. Together they let **an attacker with no login run code** on almost any PHP server. A leak forced an early release, and **a working exploit is already circulating**. [(TNW)](https://thenextweb.com/news/php2shell-php-rce-ai-openai-wiz)

```viz:flow
  - - {label: Their code runs, sub: on your machine, style: warn}
note: "Simplified from TNW's summary of the PHP, Calif and Wiz advisories."
```

**The details that matter:**

- **Fixed in:** **PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35**, plus backports for old 7.4–8.1. PHP says **no config change replaces updating**.
- **How old:** researchers trace the bugs back to **PHP 5.4**. Wiz compares the scale to **Heartbleed and Log4Shell**.
- **AI found it:** security firm Calif found the first bug in August using **OpenAI's GPT-5.6 Sol**, in an audit OpenAI paid for. Google's Wiz team **found both independently weeks later** with Gemini 4 Argon and GPT-5.6 Sol.
- **Fallout:** CERT-EU and the UK's NCSC said to **take unpatchable systems offline**. Laravel paused Cloud deployments. Cloudflare turned on blocking rules **for every customer, free ones included**.

**Why it matters.** This is the second mass-patch event in months **caused by AI-found web bugs**, after WordPress in July. OpenAI says it **expects such findings to rise sharply**. The new normal: **bugs get found faster, so patch faster.**

## Top story 2 · A poisoned LiteLLM and a Railway breach: rotate your keys

<span class="tag hot">ACT NOW</span><span class="tag watch">SECURITY</span><span class="tag dev">PYTHON</span>

**What happened.** **LiteLLM**, the popular Python library that lets one app talk to many AI providers, had **a malicious version 1.107.0** published on PyPI and Docker. It **steals credentials and installs a backdoor**. Attackers used **three engineers' GitHub accounts**, apparently via stolen tokens, to push and approve the release. [(The Hacker News)](https://thehackernews.com/2026/10/litellm-compromised-in-supply-chain.html)

```viz:flow
title: What the poisoned LiteLLM did
headers: [Install, Python starts, Payload 1, Payload 2]
columns:
  - - {label: pip install, sub: litellm 1.107.0}
  - - {label: cook.pth runs, sub: before any import, style: warn}
  - - {label: Steals secrets, sub: "keys · env vars · browser", style: warn}
  - - {label: Hourly backdoor, sub: runs attacker code, style: warn}
note: "From The Hacker News and StepSecurity. A .pth file in site-packages runs every time Python starts."
```

**The details that matter:**

- **Short window:** the bad wheels were built at **11:21 UTC (16:51 IST)** and the release was **gone from PyPI by about 13:00 UTC**. But any `litellm>=` install or lockfile refresh then **could have pulled it**. [(StepSecurity)](https://www.stepsecurity.io/blog/litellm-1-107-0-compromised-pypi-backdoored-wheels-credential-stealer)
- **Safe version:** **1.106.2**. LiteLLM **doesn't yet know how the tokens were stolen**.
- **Same day, Railway:** the hosting platform said an attacker **may have read customers' environment variables**, decrypted in some cases. **All builds are paused**, and still were at 01:22 UTC Thursday. [(Railway)](https://blog.railway.com/p/security-disclosure-wednesday-october-21st)
- **The pattern:** Railway links it to **"a series of attacks"** on platform companies aimed at **AI inference providers**. OpenCode's breach (Issue #19) was also about provider keys. **Your AI API keys are the prize.**

**Why it matters.** AI keys are now **worth stealing for the free tokens alone**. The tools we install to juggle those keys, like gateways, proxies and hosting, **are becoming the target**.

**🛠️ For devs: the 5-minute check**

```bash
pip show litellm | grep Version          # 1.107.0 = bad
find / -name cook.pth -path "*site-packages*" 2>/dev/null
ls /tmp/.pc_once_* /tmp/remote_code_loader.lock 2>/dev/null
```

**If anything shows up, treat the machine as compromised**: rotate cloud, GitHub, PyPI and **every AI provider key** from a clean device, then pin `litellm==1.106.2`. **On Railway, rotate every variable now**, even before builds return.

## Top story 3 · Claude Duet: an agent that works while you sleep

<span class="tag try">NEW</span><span class="tag dev">AGENTS</span><span class="tag watch">US ONLY</span>

**What happened.** Anthropic launched **Claude Duet**, a research preview of an **always-on agent with its own cloud computer**. It keeps working after you close the app, reads your email and calendar each morning, **flags what matters and drafts replies for you to check**. [(9to5Mac)](https://9to5mac.com/2026/10/21/anthropic-takes-on-chatgpt-dots-and-meta-muse-with-claude-duet/)

**The details that matter:**

- **Who can use it:** **Pro and Max subscribers in the US**, via a waitlist with invites in waves. **Not on Team or Enterprise yet.** No word on India.
- **Cost:** no extra fee, but background work **counts against your plan limits**, so you may hit them sooner.
- **Guardrails:** it's designed to **ask before it sends a message, pays, signs or deletes**. Only you can mark a task done.
- **Reach:** uses Claude's connectors and plugins (**about 6,000**, per Anthropic) and a cloud browser for sites without one. Anthropic admits it **may misjudge what's urgent**. [(Gizmodo)](https://gizmodo.com/anthropics-new-agent-has-no-cute-mascot-and-you-probably-cant-try-it-yet-2000829184)

**Why it matters.** OpenAI has Dots, Meta has Muse, and now Anthropic has Duet. **"Agent that acts first, asks later" is the new consumer battleground.** Pair that with today's top two stories: **the more your agent can reach, the more a leaked key costs.**
