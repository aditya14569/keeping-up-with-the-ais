# Part 1 · Learn one thing

## 🔌 MCP: plugging tools into any AI

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**Tool use (Issue #16) lets a model call your functions. MCP lets you write those functions once and plug them into every AI app.**

**MCP (Model Context Protocol)** is an open standard for connecting AI apps to tools and data. You wrap a tool, say your database or GitHub, in a small program called an **MCP server**. Any app that speaks MCP (Claude, ChatGPT, Cursor, VS Code and many more) can then **discover that tool, read its description and call it**, with no custom glue code per app.

**Analogy:** **USB-C for AI.** Before USB, every printer needed its own port and driver. Now any device fits any laptop. MCP does that for tools: **build the plug once, and it fits every AI app** that has the socket.


**Why a standard helps:** without one, 5 AI apps and 10 tools means **50 separate integrations**. With MCP it's **5 clients plus 10 servers**, and each new tool works everywhere on day one. That's why the official registry already lists **9,600+ servers**. [(Tech Times)](https://www.techtimes.com/articles/328621/20261006/six-weeks-after-google-jpmorgan-patched-mcp-flaw-us-servers-stay-exposed.htm)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Host:** the AI app you use (Claude Desktop, Cursor). It runs **one MCP client per server**.
- **Tools, resources, prompts:** the three things a server can offer: **actions** the model can take, **data** it can read, and ready-made **prompt templates**.
- **Transport:** how messages travel. **stdio** for a server on your laptop, **Streamable HTTP** for one on the web.
- **MCP Inspector:** a free debugging UI that lets you **call your server's tools by hand**.
</div>

**Why now?** Three reasons. The **2026-07-28 spec made MCP stateless**: no start-up handshake, so a server scales behind a normal load balancer. [(AAIF)](https://aaif.io/blog/mcp-2026-07-28-whats-changing-and-how-to-migrate) **MCPCon runs this Thursday and Friday** in San Jose. And today's top story shows a bank using MCP as **a safe front door for agents**.

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** open the connectors or MCP settings in Claude, ChatGPT or Cursor. **Connect one tool you use daily** (GitHub, Google Drive, Notion) and ask: "list my five most recent items." Then check **which permissions you granted**.
- **Some code:** paste the server in the box below into `server.py`, run it, then run `npx -y @modelcontextprotocol/inspector` and connect to `http://localhost:8000/mcp`. **Click your tool and call it.** You just built an MCP server.
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: a 10-line MCP server (Python SDK v1)**

```python
# pip install "mcp[cli]<2"
from mcp.server.fastmcp import FastMCP
mcp = FastMCP("Demo")

@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers"""   # the model reads this!
    return a + b

mcp.run(transport="streamable-http")
```

Add it to Claude Code with `claude mcp add --transport http demo http://localhost:8000/mcp`. [(PyPI)](https://pypi.org/project/mcp/1.29.0/) **Gotchas:** `pip install mcp` now gives **v2**, so pin `<2` to follow v1 tutorials. **The docstring is a prompt**: vague descriptions mean wrong calls. And **lock it down**: a scan of 7,000+ servers found **41% had no authentication** and 36.7% let an agent make the server fetch internal URLs (SSRF). [(Tech Times)](https://www.techtimes.com/articles/328621/20261006/six-weeks-after-google-jpmorgan-patched-mcp-flaw-us-servers-stay-exposed.htm) Building new? The old **HTTP+SSE transport is deprecated**; use Streamable HTTP. [(AAIF)](https://aaif.io/blog/mcp-2026-07-28-whats-changing-and-how-to-migrate)
</div>

## Top story 1 · Banks and big sites are locking out AI agents

<span class="tag hot">BIG DEAL</span><span class="tag dev">AGENTS</span><span class="tag learn">MCP</span>

**What happened.** Schwab CEO Rick Wurster told Bloomberg TV that Schwab **blocks outside AI agents, Meta's Muse among them,** that try to move client money. He gets a weekly report showing **"tens and twenties" blocked each week**. JPMorgan's Jamie Dimon says his bank won't let outside agents act inside its systems either. [(TNW)](https://thenextweb.com/news/schwab-blocks-ai-agents-meta-muse)

**The details that matter:**

- **It's not just banks.** Per The Verge, **Amazon has blocked Muse since 20 Sept**, after Meta refused to pull it; **Yelp lets in only agents that pay for its data**; Delta has **no deals with third-party agents**. [(AI Weekly)](https://aiweekly.co/alerts/amazon-yelp-delta-join-banks-blocking-third-party-ai-agents)
- **The real fear is passwords.** Clients hand their login to an agent, which then acts as them. Wurster's question: if something goes wrong, **"who's liable?"**
- **Schwab's side entrance:** it will run **MCP servers** so a client's chosen AI can **check balances and do research, but not move money**. [(TNW)](https://thenextweb.com/news/schwab-blocks-ai-agents-meta-muse)
- **Meta pushes back:** it says blocking hurts customers, and that **Muse can't see passwords or payment methods**. Users of Grok, OpenAI's Dots and Instinct have also hit failed tasks. [(AI Weekly)](https://aiweekly.co/alerts/amazon-yelp-delta-join-banks-blocking-third-party-ai-agents)

## Top story 2 · Anthropic pledges 5% of its shares to a public-benefit fund

<span class="tag watch">MONEY</span><span class="tag watch">JOBS</span>

**What happened.** On Sunday Anthropic announced the **Anthropic Public Benefit Fund**. Subject to a stockholder vote, it gets **5% of the company's shares now**, and the board may add **2% more for every 50% rise in company value** above a baseline it hasn't disclosed. [(Anthropic)](https://www.anthropic.com/news/public-benefit-fund)

**The details that matter:**

- **Why:** Anthropic says AI may create huge value but **"could also cause instability for many workers."** It builds on its earlier **$200M commitment on AI's labour-market effects**.
- **The shape:** a **wholly owned LLC, not a charity**, so it can mix gifts and direct payouts. Its shares **can't be used for lobbying or politics**, anywhere.
- **The bigger total:** with co-founders' pledge to give away **80% of their equity** and a staff donation match, Anthropic says **about 20% of its shares** are now set aside for public good.
- Governance details and a **public benefit report** are promised "in the coming months." [(Anthropic)](https://www.anthropic.com/news/public-benefit-fund)

**Why it matters.** It lands weeks before Anthropic's reported IPO. A fund that **grows with the share price** ties the payout to the very thing worrying people, AI taking jobs. Whether it's big help or **good PR depends on details not yet published**.

## Top story 3 · OpenAI's weekend: mystery models and a robot

<span class="tag watch">RUMOUR</span><span class="tag hot">ROBOTS</span>

**What happened.** Three unannounced model IDs, **`aurora-red-alpha`, `aurora-green-alpha` and `aurora-blue-alpha`**, showed up in OpenAI's developer interface, spread by an unverified X post from @scaling01. **OpenAI hasn't documented, priced or explained them.** [(Crypto Briefing)](https://cryptobriefing.com/openai-aurora-alpha-models-api/) Separately, on OpenAI's *Sources* podcast, **Sam Altman said "We will"** when asked if OpenAI would build a humanoid robot. [(Engadget)](https://www.engadget.com/2285040/openai-humanoid-robot-sam-altman-statement-real-challenge/)

**The details that matter:**

- **Aurora:** an earlier `aurora-alpha` appeared on OpenRouter in February. Talk that these are **faster coding (Codex) variants is speculation**; treat it as a leak, not a launch.
- **Robots:** Altman earlier told Fortune to expect **"a cool demo in 2027"**, but not robots on the streets for a few years after.
- OpenAI lists **27 robotics openings** and is reportedly designing **its own motors and actuators**. No design, price or date. [(Engadget)](https://www.engadget.com/2285040/openai-humanoid-robot-sam-altman-statement-real-challenge/)

**Why it matters.** Unlisted IDs in an API usually mean **testing ahead of a launch**, so a new model may land soon. The robot is **years out**.
