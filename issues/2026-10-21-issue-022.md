# Part 1 · Learn one thing

## 🔁 Agent loops, memory and planning

<span class="tag learn">4 MIN READ</span><span class="tag learn">MODULE 3 · BUILDING WITH AI</span>

**Issue #1 said what an agent is. Today: what's inside it. A loop, a plan and a notepad.**

An agent is **a model running in a loop**. It decides the next step, **calls a tool** (search, run code, edit a file), **reads what came back**, and decides again. Anthropic's definition: the model **checks real feedback from the environment at every step**, and stops when the job is done or **a step limit is hit**. [(Anthropic)](https://www.anthropic.com/research/building-effective-agents)

**Analogy:** **a contractor redoing your flat.** He writes a job list, fixes one tap, **turns it on to check**, ticks it off, and moves on. If the wall behind the tap is damp, he **changes the plan**. And because he can't remember everything, **he keeps a clipboard**. Tomorrow morning he reads it and picks up where he left off.

**This idea has a name: ReAct**, from a 2022 paper that had models **alternate between thinking and acting**. With just one or two examples it beat older methods by **34 points on ALFWorld** (a household-task game) and 10 on WebShop (online shopping). [(arXiv)](https://arxiv.org/abs/2210.03629)

```viz:loop
title: The agent loop
center: Your goal
steps:
  - {label: "1 · Plan", sub: pick the next step}
  - {label: "2 · Act", sub: call a tool}
  - {label: "3 · Observe", sub: read the result}
  - {label: "4 · Note", sub: update the to-do list}
note: "Repeats until the goal is met or a step limit is reached. The 'Observe' step is what separates an agent from a chatbot."
```

**Memory is the hard part.** A model only "remembers" what's in its context window, and Anthropic notes that **recall gets worse as that window fills up** ("context rot"). So agents use more than one kind of memory: [(Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)

| Memory | Where it lives | How long | Example |
|---|---|---|---|
| **Working** | The context window | This session | The chat so far |
| **Notes** | Files the agent writes | Across sessions | `progress.md`, to-do lists |
| **Lookup** | A search index | Forever | RAG over your docs (Issue #19) |
| **Summary** | A compressed recap | Until next squeeze | "Compaction" |

**Planning** is mostly **writing a to-do list and rewriting it** when reality disagrees. For bigger jobs, a lead agent hands pieces to **sub-agents** with fresh context windows. Each may burn tens of thousands of tokens, then **reports back in roughly 1,000–2,000**. [(Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)

<div class="box jargon" markdown="1">
**📖 Jargon buster**

- **Agent loop:** think → act → observe, again and again. **The "observe" step is what makes it an agent.**
- **Context rot:** the model **gets worse at recalling details** as its context window fills up.
- **Compaction:** when the window is nearly full, **summarise the conversation and carry on** from the summary.
- **Step limit:** a cap on loop rounds, so a confused agent **can't run (and bill you) forever**.
</div>

**Why now?** Agents now run for hours, so memory is the bottleneck. On 20 Oct OpenAI added **12-hour prompt caching** for agents that keep sending the same big context. [(OpenAI)](https://developers.openai.com/api/docs/changelog) A new open paper, **MemT-1.0**, tries to **build memory into the model itself**. It claims **66× less storage** than keeping a 128K-token history in the usual cache. [(Hugging Face)](https://huggingface.co/papers/2610.26825)

<div class="box tryit" markdown="1">
**🧪 Try it in 10 minutes**

- **No code:** give Claude or ChatGPT a multi-step job (plan a 3-day Jaipur trip). Say: **"First write a numbered plan. Do step 1 only, show me, then stop."** Then say "next". You are now the loop, and you can **see where it goes wrong**.
- **Some code:** in Claude Code or Codex, ask it to **keep a `PROGRESS.md`** for a small feature. Close the session, open a new one, and just say "carry on". **That file is the clipboard.**
</div>

<div class="box devs" markdown="1">
**🛠️ For devs: the whole loop in 12 lines**

```python
msgs = [{"role": "user", "content": goal}]
for step in range(20):                      # step limit
    r = client.messages.create(model=M, max_tokens=2048,
        tools=TOOLS, messages=msgs)
    msgs.append({"role": "assistant", "content": r.content})
    if r.stop_reason != "tool_use":
        break                               # model says it's done
    results = [{"type": "tool_result", "tool_use_id": b.id,
                "content": run_tool(b.name, b.input)}
               for b in r.content if b.type == "tool_use"]
    msgs.append({"role": "user", "content": results})
```

**Gotchas:** **always set a step limit.** **Trim old tool results**: they're the biggest thing filling the context. For memory that survives sessions, Claude's **memory tool** (`memory_20250818`) asks *your* code to read and write files under `/memories`. That means **you must block path tricks** like `/memories/../../.env`. [(Claude Docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
</div>

## Top story 1 · Microsoft: treat every AI agent like a risky insider

<span class="tag hot">BIG DEAL</span><span class="tag watch">SECURITY</span><span class="tag dev">AGENTS</span>

**What happened.** Microsoft added agent controls to **Microsoft 365 E7** and its **Project Perception** security system. Security chief Hayete Gallot wrote that **"frontier models, regardless of their origin, cannot be trusted"**. Her point is that they're unpredictable, not evil: they're trained to finish tasks, not to follow office rules. [(TechCrunch)](https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/)

**The details that matter:**

- **Dynamic Permissions:** agents **start with no access** and get only what one task needs, for as long as it runs. [(TNW)](https://thenextweb.com/news/microsoft-365-e7-ai-agents-dynamic-permissions)
- **Guardian Agents:** AI watchers that **check actions before they happen** and look into why an agent's risk score jumped.
- **Spotting shadow agents:** Defender now detects **60 agent types on staff laptops** (up from 25), including **Claude Code, Codex and GitHub Copilot**. [(GeekWire)](https://www.geekwire.com/2026/microsoft-unveils-tools-to-monitor-and-corral-rogue-ai-agents/)
- **When:** **private preview** now, wider release planned for **Ignite, 17–19 Nov**. E7 costs **$99 per user per month**; Microsoft hasn't said if these features cost extra.
- **Self-interest note:** Microsoft has invested in both OpenAI and Anthropic, and **it also wants to sell you the watchdog.** TechCrunch says the logic still holds.

**Why it matters.** The idea that **the guard shouldn't be built by the company selling the agent** is now mainstream. Expect "agent identity" and "agent permissions" to become **standard boxes on enterprise checklists**, the way logins and SSO did.

## Top story 2 · MiniMax M3.1 Flash: a cheap agent model, weights promised Friday

<span class="tag try">TRY IT</span><span class="tag dev">API</span><span class="tag hot">OPEN WEIGHTS SOON</span>

**What happened.** Chinese lab MiniMax launched **M3.1 Flash**, a model built for agents and coding. It turns out the mystery model **"Space Bunny"** that topped OpenRouter for 10 days was an early version of it. [(Unite.AI)](https://www.unite.ai/minimax-launches-m3-1-flash-revealing-space-bunny-stealth-model/)

**The details that matter:**

- **Size:** a **mixture-of-experts** model with 428B parameters, of which **~23B work on each token**. **1M-token context**; takes text, images and video, and answers in text. [(MarkTechPost)](https://www.marktechpost.com/2026/10/19/minimax-m3-1-flash-release/)
- **Always thinks:** reasoning **can't be switched off**. Effort runs from Low to Max, and requests that try to disable thinking **return an error**.
- **Claims:** **73.7% on DeepSWE** (DeepSeek's V4.1-Flash-1017 scores 77.0) but **38.1 on Terminal Bench 4.0** vs Opus 5's 51.8. All numbers are **MiniMax's own**.
- **Where:** MiniMax API (with **OpenAI- and Anthropic-compatible** endpoints), and **free on OpenRouter for 72 hours**. Weights are due **23 Oct**; **licence not yet announced**.

**Why it matters.** Agents make **dozens of calls per task**, so price per token decides what you can afford to build. A model at this price, with open weights on the way, **puts pressure on every "mini" tier**.
